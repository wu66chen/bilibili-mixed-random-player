# 1.4.5：关闭的移除确认框误显示

2026-11-17，本地修复，未发布。

用户打开网页后，顶部出现无标题、无歌曲内容的“取消／移出队列”框，取消也不消失。旧代码仅依赖浏览器原生 `dialog:not([open])` 默认样式；宿主页的 `dialog { display:block }` 可以覆盖它。此时弹窗本来就未打开，调用 `close()` 无法纠正 CSS 显示。

在 ego lite 合成页添加这一条样式，1.4.4 稳定复现：`open=false`，取消前后宽度均为 380。当前保留的真实测试页未自行复现这一宿主样式冲突，不能据此声称已定位用户截图所在页的具体样式来源；合成复现与截图表现一致。

1.4.5 为播放器自身确认框添加高优先级关闭状态隐藏规则，并明确打开时的定位与视口高度约束。不修改其他弹窗、队列或收藏数据。

验证：

- 19 项 ego lite DOM 回归通过，其中新增 3 项覆盖宿主 `dialog { display:block !important }`、正常打开、取消后实际隐藏。
- ego lite 实际指针：合成页 Escape 后关闭、确认移出后关闭；真实测试页正常打开和取消后关闭，队列数量不变。
- 已安装的 1.4.5 在真实测试页刷新后 `open=false`，弹窗宽度为 0，只有一个弹窗实例。
- 本次只修改确认框 CSS，未重新执行完整分 P 或长期后台播放验收。

更新后须刷新旧 B站页面，旧页面中的脚本与样式不会随管理器更新自动替换。
